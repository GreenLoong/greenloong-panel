03

绑定域名

应用前可检查已有 ddns-go 的路径和域名指向。

同一电脑的多个游戏端口可共用域名；不同电脑同时开服请使用不同子域名，例如 mc1 和 mc2。旧电脑仍在更新同名记录时，单次修改解析不能解决冲突。

正在确认实际解析服务商。域名注册商与 DNS 服务商可能不同。

使用 Edit Zone DNS 模板，并允许 Zone Read，仅授权你要绑定的域名。打开 Token 设置 ↗。Minecraft 记录会设为 DNS only（灰云）。

首次在本地填写对应服务商的密钥，保存后可留空沿用。密钥只写入本机受限目录，通用部署包不包含密钥。

此步骤可能请求 Windows 管理员授权。路由器的 IPv6 入站限制仍需单独检查。
